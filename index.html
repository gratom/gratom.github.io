Portfolio

Calamity

2D MMORPG, Sandbox, Action RPG, PC, Steam

Calamity is a 2D top-down sandbox MMORPG featuring action combat, dungeon crawling, 3-player online co-op, and a player-driven economy. Primarily focused on architectural implementation of the game's UI/UX using reactive programming patterns. Developed high-performance, dynamic UI systems and managed complex data subscriptions and aggregation from backend server events via custom server. Integrated rich UI animations, ensured seamless data binding, and contributed to general client gameplay features, bug fixes, and system enhancements.

RunCraft

Survival-Runner, Roguelike, Mobile-Android

RunCraft is a fast-paced voxel survival runner where players must manage resources, craft gear, and maintain their hunger levels during the day to battle monsters and survive the night. Players can choose unique characters and combine their perks to create a personalized playstyle. The project was developed from scratch—spanning everything from architecture to app store release—as a full-cycle indie development effort. It features a complex gameplay loop with dynamic abilities and a progression system, alongside a robust infrastructure that includes secure leaderboards, an anti-cheat system, localization, and seamless data migration during updates. In-app purchases (IAP), ad networks, and deep analytics systems were integrated, while the engine was meticulously optimized to ensure smooth performance even on decade-old mobile devices.

Cat Tree

Casual, Idle, Collections, Indie, PC, Steam

Cat Tree is a relaxing casual idle game where players collect, grow, and manage a collection of unique cats residing on a mysterious expanding tree. Architected and built the entire codebase independently from scratch within a tight two-week timeframe, serving as the sole technical developer and mentor for an indie partner. Implemented a robust modular game architecture utilizing a Service Locator pattern, a custom UI framework wrapping Unity RectTransform, state serialization for instant state save/restore, and save file versioning. Integrated complex Spine 2D cat animations and custom Editor tooling to ensure high performance and smooth visual feedback.
